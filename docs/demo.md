# Демонстрация за 90 секунд

1. Показать `examples/input/manometer.json`: только исходные значения из PDF.
2. Запустить `python3 -m cardcraft examples/input/manometer.json --demo --format markdown`. Сразу пояснить: это воспроизводимая offline-демонстрация; настоящий провайдер включается без `--demo`.
3. Показать SEO-счётчики, характеристики и источники. Отметить предупреждение о неполном описании.
4. Запустить `python3 -m cardcraft examples/input/demo-incomplete.json --demo --format markdown`. Показать «данных нет» и перечень уточнений. Уточнить, что товар синтетический.
5. Запустить `python3 -m unittest discover -s tests -v`. Объяснить, что тесты покрывают ошибки API без сетевых расходов.
6. Открыть `cardcraft/prompts.py` и `domain.py`: модель выбирает существующие ID; произвольное значение не проходит проверку.

Для live-демонстрации заранее задать ключ в окружении и проверить доступ модели. Не показывать ключ на записи экрана. Ожидаемый результат live-вызова может отличаться порядком характеристик, выбранным назначением, сценарием и предупреждениями.
