# Сопроводительное сообщение

Здравствуйте!

Подготовил Cardcraft — локальный AI-помощник для черновиков карточек контрольно-измерительных приборов. Принимает JSON через CLI или HTTP API, возвращает JSON/Markdown с SEO-блоком, характеристиками, поисковыми запросами и подсказками менеджеру.

Основное внимание уделил точности: LLM составляет редакционный план со ссылками на исходные данные, а приложение переносит технические значения без свободной генерации. Добавил проверку длины, явные пропуски данных, происхождение характеристик и обработку ошибок API. Запуск не требует сторонних Python-зависимостей; есть автоматические тесты и отдельный деморежим.

В исходном задании обнаружился только пример манометра, поэтому второй пример явно обозначен как синтетический и показывает поведение при неполных данных. Реальный вызов API требует ключа; сохранённые примеры получены в деморежиме. Ограничения и варианты развития описаны в README.

Буду рад обсудить выбор архитектуры и показать работу на ваших товарных данных.
