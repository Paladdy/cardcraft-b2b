Выполнил тестовое задание: Cardcraft — AI-помощник для подготовки черновиков карточек контрольно-измерительных приборов.

Репозиторий: https://github.com/Paladdy/cardcraft-b2b

Сервис принимает JSON через CLI или локальный HTTP API и возвращает JSON/Markdown: SEO-заголовок до 70 символов, описание на 800–1200 символов, характеристики, 3–5 поисковых запросов и блок для менеджера с параметрами подбора и вопросами заказчику.

Главный акцент — проверяемость технических данных. LLM составляет редакционный план со ссылками на исходные поля; приложение проверяет его и собирает текст из подтверждённых значений и редакционных правил. Отсутствующие данные явно отмечаются, а спорные фрагменты выносятся на проверку. Это осознанный компромисс: меньше свободного копирайтинга, больше контроля над техническими утверждениями.

Основной провайдер — OpenAI API. Дополнительно реализован запуск через локальный Ollama без внешнего API-ключа. Автоматического переключения между провайдерами нет. Есть отдельный деморежим, который явно помечен в результатах.

Проверка: 41 автоматический тест и 39 дополнительных offline-проверок. Полная цепочка с настоящей LLM проверена через Ollama на двух примерах; результаты сохранены в examples/ollama. OpenAI-адаптер покрыт тестами, однако реальный OpenAI-прогон остановился из-за отсутствия API-кредитов — это ограничение отдельно указано в README.

В предоставленном PDF был только пример JSON манометра, без данных второго товара. Поэтому второй пример явно обозначен как синтетический и демонстрирует обработку неполных характеристик.

В репозитории есть инструкция запуска, исходные данные и результаты, промпты, описание принятых решений, ограничений и возможных улучшений. Приложение работает на Python 3.10+ без сторонних runtime-зависимостей.

Буду рад обсудить архитектуру и показать работу на ваших товарных данных.
