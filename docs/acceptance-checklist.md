# Приёмка тестового задания

Проверено 6 ноября 2026. Основной провайдер — OpenAI; дополнительный — локальный Ollama. Провайдер по умолчанию не изменён.

**Результат:** 41 автоматический тест и 39 дополнительных offline-проверок прошли. Два настоящих вызова локальной LLM также успешно завершены. OpenAI-интеграция протестирована на подменённом транспорте; успешный настоящий OpenAI-прогон не подтверждён из-за исчерпанного API-баланса.

## Запуск и интерфейсы

- [x] Python 3.10, запуск без runtime-зависимостей проверен, в том числе ранее в чистом venv.
- [x] JSON принимается из файла, stdin и через локальный HTTP API.
- [x] Экспорт JSON и Markdown работает; offline-результаты воспроизводятся.
- [x] OpenAI используется по умолчанию; Ollama включается явно через `--provider ollama`.
- [x] `--demo` явно обозначен; автоматического fallback после ошибки API нет.

## Содержимое и происхождение

- [x] Заголовки двух live-карточек: 50 и 59 символов, лимит 70.
- [x] Описания: 854 и 898 символов, лимит 800–1200. Счётчики относятся к тексту JSON до Markdown-экранирования.
- [x] Поисковых запросов: 5 и 4, без дублей.
- [x] Все непустые характеристики сохранены и сверены с исходными значениями.
- [x] Все ссылки `evidence` разрешаются в исходные поля; цитаты присутствуют в источнике.
- [x] Назначения выбраны из правильных фрагментов: `d0` у манометра и `d1` у учебного измерителя.
- [x] Commercial-блок содержит аудиторию из назначения, параметры подбора и вопросы заказчику.
- [x] Пустые значения и отсутствующие обязательные поля явно отмечены.
- [x] Спорные характеристики не используются в SEO и аргументах менеджеру, но сохраняются для редакторской проверки.

## Ошибки и модель

- [x] Проверены повреждённый JSON, дубли ключей, пустые поля, неверные типы, большой ввод и отсутствие названия.
- [x] Тестами покрыты ошибки OpenAI 401/429, сетевые сбои, отказ, обрезка и повреждение ответа. Повторы ограничены.
- [x] Тестами покрыты отсутствие сервера/модели Ollama, незавершённый ответ, неверный JSON и выдуманные ID.
- [x] Реальная цепочка JSON → API локальной LLM → проверка плана → карточка пройдена на `llama3.2:3b`.
- [ ] Реальная генерация через OpenAI не завершена: HTTP 429, `credit_balance_exhausted` / `insufficient_quota`.
- [ ] Семантическая устойчивость на широком наборе паспортов, противоречий и prompt injection не доказана двумя примерами.

Наблюдение: небольшая модель пометила фразу «Учебный пример, не реальная модель» для проверки, хотя противоречия в ней нет. Это ложное срабатывание, явно сохранённое в `review_items`. Корректное назначение и характеристики при этом попали в карточку. Результат всегда имеет статус `needs_review`.

## Повторить проверки

```bash
python3 -m unittest discover -s tests -v
python3 scripts/check_acceptance.py
python3 -m cardcraft examples/input/manometer.json --provider ollama --format markdown
python3 -m cardcraft examples/input/demo-incomplete.json --provider ollama --format markdown
```

Первые две команды не вызывают платную/локальную модель. HTTP-тестам нужен loopback-порт. Последние две требуют запущенного Ollama и установленной `llama3.2:3b`. Сохранённые примеры получены без ручного редактирования карточек; следующий прогон модели может отличаться.

CI запускает тесты на Python 3.10, 3.12 и 3.13. Локальные служебные протоколы в `output/verification/` исключены из Git; проверяющий может получить их повторным запуском.
